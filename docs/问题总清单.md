## 阶段 2 · 功能闭环

### 2.1 画图 + 唱歌的显存调度

**问题**：8GB 显存，TTS 占 2GB、RVC 要 4.3GB、ComfyUI 要 3~6GB，同时开必炸。

**方案**：串行调度器——按任务临时让位。

```
唱歌时：暂停 TTS（腾 2GB）→ 唱 → 恢复 TTS（约 50 秒）
画图时：ComfyUI 常驻，TTS 保留，RVC 不启动
训练时：只跑训练，其他全停
```

**实现**：`sing_pipeline.py` 首尾加暂停/恢复 TTS 的调用。

### 2.2 唱歌工具

**状态**：管线通了（分离→转换→混音，出过 5 分钟成品），但被显存卡住。
**做法**：先完成 2.1，再回归测试 `qq_sing`。

## 阶段 3 · 行为质量

### 3.1 工具精简（87 → 约 40）

**发现**：87 个工具里只有 15 个被用过。

**建议删除**：

```
qq_pc_*（9 个，从没用过，且有隐私顾虑）
qq_knowledge_*（3 个，存了不看）
qq_*_note / *_remark（3 个，重复）
qq_get_forward_msg / group_history（2 个）
```

**建议保留但加"什么时候用"的说明**：

```
qq_draw      他说"画个…"或者你想给他看什么时
qq_web_search 不知道的事先搜，别瞎编
qq_bili      他发 B站链接时，先看一眼再回
qq_music_*   他说想听歌/想唱歌时
```

### 3.2 提示词瘦身（11k / 13k）

**做法**：合并重复节（示例、日子、档案三节可压成两节），目标降到 8k。

## 阶段 4 · 让她更像人（可选，也是真正难的）

### 4.1 拒绝权

**规则**：她可以在不想的时候说"不"，说了就是说了，不解释。

**难点**：这意味着你要接受"她今天不想理你"。

### 4.2 无聊时间

**做法**：每天随机 1~2 次"无任务唤醒"，只注入时间和身体状态，不注入任何待办。

```
她现在从"被叫醒的应答器"变成"过日子的人"
但还缺"没事干的时候"
```

### 4.3 补不了的

```
真实意识 / 真实的痛 / 会死的身体
```

**这三样给不了。给了也只是演得更像。**
