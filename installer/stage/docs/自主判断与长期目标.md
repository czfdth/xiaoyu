# 自主判断、取舍与长期坚持

这部分复用已有画册和兴趣练习，不再维护一套待办。`state/agency.json` 只保存主目标引用、取舍理由、备选与机会成本，以及实际工作机会的预留和投递结果。旧角色、记忆、连续性记录和项目不会迁移或重置。

## 实际行为

- 首次选择从现有可执行计划中进行，用户请求优先，自己的练习也能获得位置。主目标一旦选定，会跨天保留；不会因为又想到一个主题就每轮重选。
- 到期约定优先处理。之后的新用户任务可以临时让路；原主目标保持不变。目标受阻时可推进已有备选，条件恢复后返回原方向。自动调度不取消原计划。
- 无新用户明确决定时，改变未完成且未受阻的方向，需要至少两项新的实际作品检查证据且已过七天，或三项新成果。旧作品、被替换的文件和单纯唤醒次数不能满足条件。新用户决定须有真实原话、时间和明确目标。
- 新开练习、放弃当前方向，以及自主回合里的作品关联和检查，都有服务端执行校验。自主操作只能推进本轮实际预留的目标；不能换工具、换唤醒原因或借其他项目编号绕过。一轮产生新成果后先收尾，不能连做下一步；画册最终归档仍可完成。
- 自主工作一天最多三个机会，机会间隔至少30分钟。相同证据状态下三次没有进展，暂停自动推进；跨天不会把停滞洗掉。新成果或用户明确调整后继续，原历史保留。当日预算跨目标共享，重新选目标不能洗预算。
- 实际生活时段脚本沿主目标调度；停滞、休息或预算用完时不另起活动。安静要求继续约束联系，内部工作不自动向QQ汇报。

## 进展与边界

作品必须仍能从现有允许的作品目录读取，且与检查记录的哈希一致。依据仍可能是代理自评，不能包装成用户认可、客观能力或主观欲望。跨天测试通过可控时钟验证状态和调度，不等于已经观察到连续多天的真实自主活动。

`qq_agency` 可查看当前主目标、取舍、真实进展和停滞原因，也可在符合条件时引用已有目标作阶段调整。它不会任意删除旧任务、绕过用户权限，或因为一句夸奖、一次工具故障就改写整个自我认识。

测试包括目标保持、资源预算、用户任务临时优先、受阻恢复、源消息校验、实际操作拦截、重启接续，以及真实bridge/MCP接本地假QQ协议。真实QQ不接收测试消息。
